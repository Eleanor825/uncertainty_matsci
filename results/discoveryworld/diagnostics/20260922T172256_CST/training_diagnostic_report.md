# DW 训练充分性审计：固定开发集诊断

结论：当前 NN 已充分拟合训练样本，不支持“再盲目增加训练步数即可解决”。Internal 后段呈现过度自信/过拟合的模式；这不等于训练方案已充分泛化，也不能据此断言图信号无用。已有 OP5 / Full 固定 200 步模型保持不变。

实跑完成：53.8775 秒，4 个 NN × 200 步及 4 个经典模型，共 16 个预声明 NN 检查点。world 0 拟合 60 行/3 episodes，world 1 温度校准 60 行/3 episodes，world 2 开发评估 40 行/2 episodes。无新增图、LLM、环境调用或 heldout 结果读取。

Internal 指完整风险特征模型，不是一次在线 Full 策略轨迹。GraphOnly 为 153 个图特征，NoGraph 为 140 个 hidden/sampling/action 特征，OutputAction 为 10 个廉价特征；全部沿用原 TrainOnlyFeatures。step 0 已含在 world 0 标签上拟合的 error-prototype 等预处理，不能当作完全未学习的随机基线。

## 训练与泛化证据

- 四组到 200 步的训练 AUROC 均为 1，未校准训练 NLL 分别为 Internal 0.000144、GraphOnly 0.000381、NoGraph 0.000206、OutputAction 0.002116。没有训练损失降不下来或优化未启动的证据；这仅说明样本内拟合充分。
- Internal 50→200 步：训练原始 NLL 0.009203→0.000144；开发原始 NLL 0.169148→0.336776；校准开发 NLL 0.173622→0.199944、Brier 0.055349→0.064438，而 AUROC 始终 0.970000。温度由 1.877→2.656，缓解过度自信但未完全消除开发概率误差增长。此固定切分支持后段过拟合/过度自信，不证明 50 步是可推广的最优点。
- GraphOnly 50→200 步：原始开发 NLL 0.586336→0.945713；温度校准后 NLL 0.426535→0.424566、AUROC 0.910000→0.913333，变化很小且非单调。200 步校准集 NLL 0.181287，对开发集 0.424566，提示图特征跨 world 的概率泛化存在问题，但不能区分分布变化、有限样本和特征设计各自贡献。
- NoGraph 50→200 步校准开发 NLL 0.264364→0.236879、Brier 0.075955→0.068714；AUROC 经 100 步 0.970000 回到 200 步 0.960000。OutputAction 校准开发 NLL 0.264715→0.253498、AUROC 0.943333→0.960000，中间并非单调。因此不能把 Internal 的 50 步观察机械套到所有特征组。

## GBC 与 L2 对照

L2 logistic：C=1、lbfgs、l1_ratio=0、最多 1000 次迭代；GraphOnly / Internal 实际分别 14 / 17 次迭代完成，无收敛警告。GBC 两组完成预声明的 100 棵树且无警告；日志的 converged=true 仅表示无 ConvergenceWarning，不能解释为梯度优化器已收敛。两类模型均使用 N×原等 episode 权重，平均为 1，避免无意改变 L2 正则强度。

| 模型 | Fit：NLL / Brier / AUROC | Calibration：NLL / Brier / AUROC | Development：NLL / Brier / AUROC |
|---|---|---|---|
| GBC_GraphOnly | 0.103830 / 0.009731 / 1.000000 | 0.324067 / 0.089819 / 0.889140 | 0.382173 / 0.110384 / 0.850000 |
| GBC_Internal | 0.068717 / 0.004414 / 1.000000 | 0.299020 / 0.089202 / 0.966063 | 0.291646 / 0.087590 / 0.941667 |
| L2Logistic_GraphOnly | 0.032918 / 0.001520 / 1.000000 | 0.173476 / 0.045839 / 0.977376 | 0.397820 / 0.081192 / 0.900000 |
| L2Logistic_Internal | 0.012851 / 0.000356 / 1.000000 | 0.156132 / 0.051389 / 0.985294 | 0.245014 / 0.076039 / 0.963333 |

经典对照没有显示“换回默认 GBC 就恢复更好的开发排序”。GraphOnly 的 GBC / L2 开发 AUROC 为 0.850000 / 0.900000，低于 NN 的 0.913333；NLL 则分别为 0.382173 / 0.397820，低于 NN 的 0.424566，说明排序与概率质量不能混成单一结论。Internal 的 GBC / L2 开发 AUROC 为 0.941667 / 0.963333，也未优于 NN 0.970000。它们都是在当前特征和数据上的固定对照，不是原 CRV 整套方法的复现。

## 证据边界与下一步

当前最强证据是样本内拟合已经充分，Internal 继续压低训练误差伴随开发概率误差恶化。图信号并非已证明无用：固定 200 步 Internal 相对 NoGraph 的开发 AUROC 增加 0.010000，Brier 下降 0.004275，NLL 下降 0.036935；但只有 2 个相关 episode、1 个开发 world，既没有足够独立重复，也没有显著性或在线收益证据。153/293 原始特征对应仅 60 拟合行，划分变化和高维估计方差都可能影响这些差值。

当前生产模型继续保持固定200步；本诊断不以已观察的 world2 开发结果替换停止规则、阈值或检查点。
