# 原 MADE critic 的训练、标签与校准

仅原 MADE 证据；未使用其他 benchmark 的 checkpoint metadata。源码摘录来自实际 support-aware 源包，完整源 SHA 已与原 extractor provenance 核对；公开的是有行号和完整源 SHA 的精确摘录。

- **数据与独立性**：AlAuHf seeds1/2/3 的150次 train ORB；AlPdSm seed1 的50次 dev ORB。302/84 proposals，293/83 有未来标签（train204正89负，dev42正41负）；10未执行/未知不当负样本。只有150/50独立物理结果，分别被1–8/1–4个前序工具行复用。dev 同时用于 epoch 选择和温度，不能称独立校准后测试。[NN_report](../../../results/development/nn_information_audit/20260919T080602_CST/report.md)。
- **语义**：未来 scalar 是非 stable-new；不是推理错误。generation_invalid 与 `1−sampling.valid_json_action` 在386/386行相等，完美格式 AUC 不能证明图预测科学失败。typed 各头缺类别支持时不能据缺省值宣称会预测。没有已发现 future label 写入生成前特征的证据。[NN_report](../../../results/development/nn_information_audit/20260919T080602_CST/report.md)；[rollouts.py:380](code/historical_excerpts.json)。
- **实际训练**：298原始特征（153图、130hidden、9action、6sampling），121列训练常量；train-only median/标准化/错误原型，加 missing indicators 后599维、MLP64/64 GELU、42,625参数。AdamW/BCE按episode加权而非平衡正负类。模型实际跑16 epochs，dev BCE 第1轮 .694714、第8轮 .802658、第16轮 .747373；选第1轮，仅保留2 updates。保存模型 train raw AUROC .595230、NLL .688913；dev .516260/.694714。后续开发恶化不等于证明训练充分，保留2步也不等于多训必然有效；原历史只存 dev BCE，**没有逐轮 train loss 可作完整收敛判断**。[NN_training_evidence](critic_metrics.json)；[uncertainty.py:49](code/historical_excerpts.json)、[uncertainty.py:116](code/historical_excerpts.json)。
- **压缩来自真实校准**：原温度54.597804，接近预设 exp(4)=54.598150 上限；同一 dev 上最小化 NLL，非手写固定 .5。p≥.6 要求 raw logit≥22.137504。正温度理论上保序，不能把压缩本身称随机排名（有限精度会产生极少并列差异）。原 proposal dev AUC .516260；去重复看最后select的50事件 AUC .4928。calibrated Brier .250006，近常数 .5 的 .25。已有 dev 发生率 .5060、train .6962，加上弱 logit 支持向 .5 收缩；不能把温度变小来人为造触发。[uncertainty.py:163](code/historical_excerpts.json)；[NN_report](../../../results/development/nn_information_audit/20260919T080602_CST/report.md)。
- **阈值来自固定控制协议**：.6 是运行参数，evaluate/full_ES 从继承 core protocol 取；controller 默认也是 .6，未从本轮 heldout outcomes 拟合。校准最小 NLL 并不联合保证这个固定操作点的召回/收益。[failure_controller.py:205](code/historical_excerpts.json)。本地未重新读取完整原 core 的历史选阈推导，因此不声称其为原论文最优点。
- **missing 不是伪 .5 控制**：原拟合/scoring376有标签行都具图；9无图proposal全是generation-invalid，训练没有合法缺图分布覆盖。当前 support-aware 缺图将 scalar/types 设 None、flag False、unknown-neutral，不按 NN 风险重排；保留原数值仅供诊断。这能解释控制覆盖下降及 typed 泛化风险，不能把其输出说成默认 .5。[support_control.py:39](code/historical_excerpts.json)、[support_control.py:76](code/historical_excerpts.json)。
- **已有轻量训练对照**：另命名空间的3训练episode LOEO时长诊断已真实8个初始化、1240updates；Internal选8步，CV BCE .665039，差于 fold train-prior .636932；external15列选32步，CV .628878。dev Internal AUC .495935，external .430894，温度均≈54.598，cal Brier .250076/.250046。这削弱“只要继续训练就好”的说法，不证明不同数据/表示永远无信号，也没有替换生产 NN。[grouped_NN_report](../../../results/development/grouped_scalar_risk/20260919T192455_CST/report.md)。

可判定：小且相关的数据、目标时域与数据域迁移是可信限制；原温度压缩和门不触发是实测机制。无法判定：无完整 train 曲线时不能归咎优化未收敛；无执行反事实时不能归咎拒绝优质晶体；无新的 train-only 方案验证时不能归咎图信号本质无用。
